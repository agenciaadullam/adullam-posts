# Adullam — Posts

Posts prontos da Agência Adullam e dos clientes, organizados para agendamento no Metricool.

```
<cliente>/<ano-mês>/<dia-tema>/   slides (slide-01.jpg…), legenda.md e o gerador
fotos/<cliente>/                  fotos reais das visitas para usar nos posts
_sistema/                         fontes, logos, CSS base e o script que gera os JPGs
```

Clientes: `adullam`, `ranna-farma`, `ana-fitness`, `01-espetos`.

Este repositório é público porque o Metricool precisa baixar as imagens. Não coloque aqui contratos, orçamentos nem dados de clientes.
